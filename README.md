# walder.reyes

Sitio personal de **Walder Reyes**: Software Engineer · Product Builder · Entrepreneur.

Sitio estático, sin servidor ni dependencias de compilación. Tiene modo claro y oscuro, está en español e inglés, y usa un espacio cuántico en 3D hecho con Three.js.

## Estructura

| Archivo | Descripción |
| --- | --- |
| `index.html` | Página principal |
| `laboratorio/ecosistema-3d.html` | Laboratorio 3D "Ecosistema \|ψ⟩" |
| `assets/favicon.png` | Ícono de la pestaña |
| `assets/logo.svg` | Logo \|ψ⟩ vectorial |
| `assets/og-image.png` | Imagen al compartir el enlace |

## Ver en local

Abre `index.html` en el navegador. Necesita internet para las tipografías y la librería 3D.

## Publicación

GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

## Editar textos

Los textos en español están en el HTML. Las traducciones al inglés están en el objeto `EN` dentro del `<script>` de `index.html`.
